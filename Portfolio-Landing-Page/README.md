# 💼 Portfolio Landing Page

A responsive portfolio-style landing page built with **HTML, CSS and vanilla JavaScript**.
This is a practice project to apply what I learned about layout, responsive design and DOM manipulation.

🔗 **Live demo:** [View the website](https://mustapha-aa.github.io/Projects-Web-HTML-CSS-JavaScript/Portfolio-Landing-Page/)

![Preview](screenshot.png)

## ✨ Features

- Fixed header with smooth-scroll navigation
- Active nav link that follows the section currently in view (`IntersectionObserver`)
- Mobile menu with a toggle button (hamburger / close icon)
- Fully responsive layout (desktop, tablet, mobile) using media queries
- Sections: Home, About, Services, Portfolio, Contact
- Hover effects on service cards and project thumbnails (zoom, rotate and overlay)
- Contact form with built-in validation (demo only, no data is sent)

## 🛠️ Built With

- **HTML5**: semantic structure
- **CSS3**: Flexbox, media queries, transitions and hover effects
- **JavaScript (ES6)**: DOM manipulation and `IntersectionObserver`
- [Font Awesome](https://fontawesome.com/) for icons
- [Google Fonts](https://fonts.google.com/) (Rubik)

## 🚀 Getting Started

1. Clone the repository:
2. Open `index.html` in your browser
   (or use the **Live Server** extension in VS Code).

No installation or build step is needed.

## 🌐 Deployment

The site is hosted for free with **GitHub Pages**:
`Settings → Pages → Branch: main → Save`.
